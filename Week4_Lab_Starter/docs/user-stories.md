# User Stories

## User Story 1: Create a Task

As a student, I want to create a task, so that I can keep track of work that I need to complete.

### Acceptance Criteria
- The system allows the student to enter a task title and save the task.
- The newly created task appears in the task list.

## User Story 2: View Tasks

As a student, I want to view my task list, so that I can see which tasks I need to complete.

### Acceptance Criteria
- The system displays all tasks created by the student.
- Each task displays its title and completion status.

## User Story 3: Mark a Task as Complete

As a student, I want to mark a task as complete, so that I can track my progress.

### Acceptance Criteria
- The system allows the student to mark a task as complete.
- The task's status changes to completed and is displayed accordingly.
